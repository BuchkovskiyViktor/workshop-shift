.B.A.D.Workshop — тестовая PWA v3

Что изменено:
- Роль не выбирается внутри приложения. Она закреплена за учётной записью.
- Новая заявка всегда создаётся как сотрудник и требует подтверждения руководителя.
- Проекты создаёт и закрывает только руководитель.
- Тарифы каждого сотрудника задаёт только руководитель.
- У каждого участка смены есть публичный комментарий сотрудника.
- Руководитель может ответить на комментарий; его ответ отображается отдельно и курсивом.
- У сотрудника есть приватная заметка к участку, которая не показывается в интерфейсе руководителя.
- Сотрудник может заявлять личные расходы и транспорт для компенсации.
- Руководитель отдельно вносит прямые затраты проекта.
- Панель руководителя содержит текущих сотрудников, проекты, суммы и почасовую картину.
- Панель автоматически пересчитывается раз в минуту, а данные группируются по часовым интервалам.

Установка на GitHub Pages:
1. Замените файлы в корне репозитория файлами из этой папки.
2. Убедитесь, что index.html находится в корне.
3. Сделайте Commit changes.
4. Откройте обновлённый адрес GitHub Pages.
5. Если iPhone показывает старую версию, закройте приложение с экрана многозадачности и откройте снова. При необходимости удалите и снова добавьте иконку на экран Домой.

ВАЖНО:
Эта версия пока хранит тестовые данные локально на конкретном устройстве.
Полноценное разделение приватных заметок на уровне безопасности и общий многопользовательский доступ будут реализованы при подключении Supabase. Приватные заметки должны храниться в отдельной таблице с RLS, доступной только их автору.
