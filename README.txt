.B.A.D.Workshop v4 — тестовая PWA

ЧТО ИЗМЕНЕНО
- Убрана отдельная кнопка «Транспорт».
- В «+ Расход» добавлены: Личный транспорт, Такси, Обед, Закупки, Материалы, Парковка, Прочее.
- Полная смена = 10 часов.
- До 10 часов оплата пропорциональна фактически отработанному времени.
- Время округляется к ближайшим 15 минутам: 7 мин -> 0, 8 мин -> 15.
- После 10 часов автоматически считается переработка.
- Сотрудник видит часы и сумму переработки.
- Типы смен: Базовая, Проектная, Другое.
- Руководитель задаёт отдельную полную ставку и ставку переработки для каждого типа смены каждого сотрудника.
- В проекте можно переопределить ставку переработки для конкретного сотрудника и типа смены.
- Руководитель записывает выплаты сотрудникам. Сотрудник видит заработано / расходы к возврату / выплачено / осталось.
- Руководитель записывает смету и фактически полученные деньги по проектам.
- Аналитика по проектам, сотрудникам и общему балансу мастерской.
- Публичные комментарии сотрудника и ответы руководителя сохранены.
- Приватная заметка сотрудника остаётся только в интерфейсе сотрудника.

ВАЖНО
Эта версия пока хранит тестовые данные в localStorage конкретного устройства. Для реальной работы между несколькими телефонами нужен следующий серверный этап (Supabase + авторизация + RLS).
